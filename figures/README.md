# `figures/`

All plots generated by the notebooks in `../src/`. Grouped by purpose:

- **EDA / outcome breakdowns** — `outcome_type_distribution*.png`, `outcome_by_*` (by age group, sex, intake type, intactness, name, …), `cats_colors_outcome.png`, `dogs_colors_outcome.png`.
- **Hyperparameter tuning** — `hyperparameter_plots_*.png`, `hyperparameter_heatmaps_elasticnet.png`.
- **Model evaluation** — `aggregated_test_scores.png`, `confusion_matrix_XGB_test.png`, `confusion_matrix_normalized_XGB_test.png`.
- **Feature importance** — `permutation_importance_plot.png`, `xgboost_importance_*.png` (gain / cover / weight variants).
- **SHAP** — `global_shap_importance.png`, `local_shap_bar_*_correct.png`, and interactive `local_shap_force_*_correct.html` force plots (open in a browser). Per-class local SHAP bars are also duplicated under `shaplocal/`.
